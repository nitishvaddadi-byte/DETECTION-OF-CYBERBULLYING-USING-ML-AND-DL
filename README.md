# Cyberbullying Detection Using Machine Learning and Deep Learning

## 📌 Project Overview

Cyberbullying has become a serious issue with the increasing use of social media and online communication platforms. The purpose of this project is to develop a system capable of identifying and classifying cyberbullying and offensive content using Machine Learning and Deep Learning techniques.

The project analyzes textual and image-based content and applies different machine learning and deep learning models to detect potentially harmful content.

## 🎯 Objectives

* Detect cyberbullying and offensive content from online text.
* Analyze text using Natural Language Processing (NLP) techniques.
* Apply Machine Learning and Deep Learning models for classification.
* Explore image-based cyberbullying detection.
* Develop a web-based interface for interacting with the detection system.
* Compare different approaches for cyberbullying detection.

## 🧠 Models Used

### Machine Learning

* Support Vector Machine (SVM)

### Deep Learning

* BiLSTM-BiGRU
* RoBERTa

### Image Classification

* Image-based classification for detecting potentially harmful content.

## 🖥️ Application

A web-based interface was developed using **Streamlit** to provide an interactive way to use the cyberbullying detection system.

The application supports the project's detection workflow and provides a user-friendly interface for classification.

## 📊 Project Components

The project consists of multiple components:

1. **Text Preprocessing** – Processing textual content for analysis.
2. **Machine Learning Classification** – Using SVM for classification.
3. **Deep Learning Classification** – Using BiLSTM-BiGRU and RoBERTa.
4. **Image Classification** – Analyzing image-based content.
5. **Web Application** – Providing an interactive interface through Streamlit.
